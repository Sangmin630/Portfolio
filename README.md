## 프로젝트 개요

GameOps는 게임 고객 문의를 자동 분류하고 근거 기반 답변을 제공하는 AI 고객센터 운영 시스템입니다.

게임사의 FAQ, 정책 문서, 커뮤니티 문의, 결제 및 아이템 지급 로그를 활용하여 사용자의 문의를 자동 처리하고, 운영자 검수 및 주간 운영 리포트 생성까지 지원하는 AI 기반 CS 플랫폼을 개발했습니다.

---

## 담당 역할

### 데이터 아키텍처 설계

* PostgreSQL 기반 RDBMS 설계
* pgvector 기반 Vector DB 설계
* ERD 작성 및 데이터 모델링

### RAG 데이터 파이프라인 구축

* FAQ / 정책 / 공지 / 커뮤니티 데이터 수집
* 문서 정제 및 청킹 전략 설계
* 임베딩 및 검색 파이프라인 구축

### 챗봇 성능 개선

* Rule-based Dispatch 적용
* Redis Cache 적용
* Retrieval 최적화

* 약 60% Latency 개선
